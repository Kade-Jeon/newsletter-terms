# policy-site

베리타(뉴스레터) 정책 문서 전용 정적 사이트 프로젝트입니다.

## 파일 구조

- `index.html`: 정책 문서 허브
- `terms.html`: 서비스 이용약관
- `privacy.html`: 개인정보 처리방침
- `styles.css`: 모바일/태블릿 반응형 스타일

## 배포(별도 레포 권장)

이 폴더를 별도 GitHub 저장소로 분리한 뒤 GitHub Pages를 활성화하면 됩니다.

예시 URL:

- `https://<github-id>.github.io/<repo>/terms.html`
- `https://<github-id>.github.io/<repo>/privacy.html`

## 수정 필요 항목

- 문의 이메일: `contact@poom.at`
